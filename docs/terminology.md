# Ableton Live → Ardour

| Ableton Live | Ardour | Ardoton wording |
|---|---|---|
| Live Set | Session | Session |
| Arrangement View | Editor | Arrangement · Editor |
| Session View | Cue Grid | Session · Cues |
| Clip | Region or Cue clip | Clip / Region |
| Scene | Cue | Scene / Cue |
| Device | Processor or plugin | Device / Processor |
| Device Chain | Processor Box | Devices |
| Return Track | Audio bus with aux sends | Return / Bus |
| Main Track | Master bus | Master |
| Browser | Several lists and plugin selectors | Browser |
| Track Group | Route Group, subgroup bus, or VCA | Group |
| Take Lane | Playlist or layer | Take |
| Clip View | Region or Cue editor | Clip |
| Device View | Processor/plugin pane | Devices |
| Consolidate | Consolidate Range | Consolidate |
| Freeze / Flatten | Bounce or freeze workflow | Bounce / Freeze |
| Automation Arm | Touch, Write, or Latch state | Automation Arm |
| Launch Quantization | Launch Quantize | Launch Quantization |
| Follow Action | Follow Action | Follow Action |

Not every term is an exact equivalence. In particular, Ardour has no direct equivalent to Live's local Warp Marker workflow, Back to Arrangement behavior, or captured Session performance.
