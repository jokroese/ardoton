# Profile pack

Files that will eventually be applied into an Ardour 9.7 user config live here.

Create each subdirectory when its first real file exists:

| Directory | Role |
|---|---|
| `keybindings/` | Live-oriented keymap and context rules |
| `theme/` | Optional visual / terminology overlays |
| `scripts/` | Lua helpers |
| `templates/` | Session templates and related defaults |

Until those directories exist, treat this tree as planning only. Do not copy anything into Ardour by hand unless you know how to reverse the change. See `installer/README.md` for the intended backup → apply → restore flow.
